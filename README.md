🛒 Supermarket Sales Analysis using Python & Pandas
Overview:
This project provides an Exploratory Data Analysis (EDA) on supermarket sales data containing 1,000 transactions across multiple retail branches. The analysis focuses on data validation, basic statistical summary, and visual distribution of total sales revenue using Python, Pandas, and Matplotlib.
Key Features & Analysis Steps:
 * Data Inspection: Loaded dataset (1000 rows, 12 columns) and checked structure.
 * Data Cleaning: Verified zero missing values (df.isnull().sum()) across all attributes.
 * Statistical Analysis: Calculated numerical summary metrics (describe()) for prices, quantities, and profit margins.
 * Data Visualization: Built histograms to visualize the distribution pattern of total sales values (total_price).
Tech Stack:
 * Language: Python
 * Libraries: Pandas, Matplotlib
